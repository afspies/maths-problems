# Hadwiger–Nelson: chromatic number of the plane ≥ 6?

## Statement
χ(plane) = minimum colors so no two points at Euclidean distance 1 share a color.
Known: 5 ≤ χ ≤ 7. De Grey (2018) found a 5-chromatic unit-distance graph (1581
vertices, later reduced to 509 by Heule and the Polymath16 effort). A 6-chromatic
unit-distance graph would be the next jump — a finite, machine-checkable certificate.

## Certificate + verifier
- Candidate: finite vertex set V ⊂ R² given as exact algebraic points (typically in
  a ring like Z[ω, √k]/… — de Grey's graphs live in rings generated by roots of
  unity), edge set = pairs at exact distance 1.
- Verify distances exactly (symbolic norm computations, no floats).
- Verify non-5-colorability with a SAT solver + DRAT proof (drat-trim), exactly as
  Heule did for the 5-chromatic case. Cheap, standard, trustworthy.

## Approach notes
- Brute search is hopeless; de Grey's construction was structural: assemble graphs
  from Moser-spindle-like gadgets over rings Z[ω₁, ω₃, ω₄] where a parity/spindle
  obstruction forces color rigidity, then fuse copies to create contradiction.
- The plausible path to 6-chromatic: find a gadget forcing "in any 6-coloring, some
  configuration is monochromatic-constrained" analogous to de Grey's Lemma on
  mono triples in hexagonal clusters, then product/fuse. Expect the certificate, if
  it exists at reachable size, to be orders of magnitude larger than 509 vertices —
  plan the pipeline for 10⁴–10⁶ vertices (incremental SAT, symmetry breaking,
  subgraph minimization à la Polymath16).
- Realistic session deliverables: working exact-arithmetic graph builder over
  cyclotomic-ish rings, reproduction of the 509/517-vertex 5-chromatic verification,
  gadget-search harness with SAT-in-the-loop scoring (e.g. count of admissible
  6-colorings of candidate gadgets, forced-coloring density).

## First steps
1. Reproduce: build the known 5-chromatic graph (Heule's 509-vertex graph is
   published with coordinates), verify unit distances exactly, SAT-verify
   non-4-colorability... then non-5-colorability of de Grey's original.
2. Build the gadget library (Moser spindle, hexagonal clusters, spindle products).
3. Search over ring extensions for 6-color-rigidity gadgets.
