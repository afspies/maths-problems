# Attack angles

- `sticky-multiscale/`: improve the trilinear `13/4` branch using balanced
  structure across scales.
- `semialgebraic-reduction/`: replace the failed R⁴ convex reduction with
  scale-aware bounded-complexity grains, starting at degree two.
- `transverse-quadric-stacks/`: a proved harmonic-overlap union lemma for an
  infinite one-parameter stack of ruled quadratic grains.

These are distinct bridges. A ruled grain appearing in the inverse
trilinear problem does not by itself prove the general-to-sticky reduction.
