# Two-level source audit

## Bohn et al., *Enumeration of 2-level polytopes*

Primary source: arXiv:1703.01943v2.

Facts used in `results/two-level-green-boundary.md`:

- every two-level polytope has a Boolean vertex embedding;
- combinatorial equivalence and affine equivalence coincide in the
  two-level class;
- the enumeration algorithm is inductive over prescribed facets and is
  supplied with a completeness proof;
- dimension four has exactly nineteen affine/combinatorial types;
- exactly eleven dimension-four types have a simple vertex.

The present campaign does not import a database verdict about terminality.
It independently constructs Boolean representatives, verifies two-levelness
and exact facet data, and checks explicit rational shadow-speed
certificates. The published count is used only to certify that the eight
pairwise-distinct no-simple-vertex representatives exhaust the eight types
not covered by the structural simple-vertex proof.

This is a bounded boundary classification, not the main general-polytope
route. No inference about arbitrary terminal four-polytope face lattices is
drawn from it.
